📋 Project Overview

This repository contains automated tests for Wildberries.ru, one of the largest Russian e-commerce platforms. The framework is designed to showcase advanced test automation skills including page object pattern, parallel execution, and CI/CD integration.
🛠 Tech Stack

    Programming Language: Python 3.8+

    Test Framework: pytest

    Web Automation: Selenium WebDriver 4.15

    Reporting: Allure Framework, pytest-html

    CI/CD: GitHub Actions

    Additional Tools:

        webdriver-manager (automatic driver management)

        python-dotenv (environment configuration)

        pytest-xdist (parallel execution)

        flake8, black (code quality)
